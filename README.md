# Collectendo

Application web de gestion de collections de jeux vidéo utilisant l'API IGDB.

## Fonctionnalités
- Recherche de jeux
- Dernières sorties
- Dark mode persistant
- Gestion utilisateur
- Collection personnalisée

## Stack
- PHP MVC
- MySQL
- JavaScript
- HTML/CSS

## Objectifs
Projet personnel visant à évoluer vers une architecture Next.js / TypeScript.
